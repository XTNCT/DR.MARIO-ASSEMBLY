# DR.MARIO-ASSEMBLY
An assembly clone of the classic Dr.Mario Game
# How to Play
P for pause
A(move pill left)
S(down/accelerate)
D(move pill right)
# Game mechanics
Match 4 same colored blocks(vertical/horizontal) to elimiate.  
The pill and the germs are all considered as blocks
# Win Condition
eliminate all germs
# Lose Condition
Filled the jar
